# Vulnerability Assessment & Offensive Security Guide

Welcome to the **VA-WEEK-3** security repository[cite: 2]. 

## Overview

This reference guide provides a practical overview of core offensive security techniques and defensive mitigations across five key attack vectors[cite: 1, 2]:

* **Credential Guessing**[cite: 1]
* **File / Web Cracking**[cite: 1]
* **Hash Cracking**[cite: 1]
* **Key / Passphrase Cracking**[cite: 1]
* **Wireless / WPA Cracking**[cite: 1]

Designed as a quick-reference cheat sheet, it pairs common target scenarios and open-source tools with practical command syntax and recommended security controls to help defenders recognize attack patterns and harden their systems[cite: 1, 2].
